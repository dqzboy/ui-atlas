# UI Atlas

给 AI 编程助手用的 UI 参考技能，帮助你把“让按钮更有手感”“加一点动效”“优化后台布局”等想法，落成具体的界面与交互。

内置 **191 条参考、18 个分类**，覆盖常用组件、交互动效、页面布局、材质与排版。提供精选参考图和文字实现配方，帮助 AI 选择合适的方案，在现有项目中实现并核对效果。

## 安装

直接告诉你的 AI 编程助手：

```text
帮我安装 ui-atlas 这个 skill：github.com/dqzboy/ui-atlas
```

也可以运行：

```bash
npx skills add dqzboy/ui-atlas
```

## 使用

安装后，在需求中加上 `使用 $ui-atlas`，说明要改的界面和期望效果即可。

**调整组件细节**

```text
使用 $ui-atlas，让现有按钮更有点击手感。
按下时轻微下沉，阴影同步收拢，保持现有按钮尺寸和主次层级。
```

**添加交互动效**

```text
使用 $ui-atlas，为推荐套餐卡片添加沿边框移动的流光。
保持卡片内容不变，动效克制，并检查实际效果。
```

**优化页面布局**

```text
使用 $ui-atlas，优化这个后台首页的信息层级。
突出核心指标和待办任务，保留现有业务功能，并适配窄屏。
```

## 参考内容

- **基础组件**：按钮、表单、卡片、表格、浮层、加载与错误状态。
- **交互动效**：滚动、拖拽、磁吸、回弹、错峰、流光、文字与背景效果。
- **页面布局**：Dashboard、企业工作台、移动服务门户、文档中心，以及官网与演示页面的设计方法。
- **质感细节**：卡片材质、统一图标、圆角、阴影、中英文排版，以及 [12 份实现配方](references/craft-recipes.md)。
