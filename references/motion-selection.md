# 20 种网页动效选型与提示词

先确定改变的是滚动进度、指针位置、路由还是业务状态，再选效果。保留项目现有触发、数据和导航语义；没有明确触发的视觉演示不能直接变成整站默认行为。静态图只展示可见结果，连续路径、节奏与中断在实际项目中验证。

## 滚动与视觉揭示

| 效果 | 适用与实现提示词 | 参考与核对 |
|---|---|---|
| 01 滚动绑定 / Scroll-linked Animation | 把展示区域的滚动进度映射到产品拆解、位移或透明度，前后滚动可逆。 | [滚动进度绑定](motion.md#scroll-linked)，明确起止区间，不替换为一次性滚动出现。 |
| 02 粒子聚合 / Particle Morph | 让分散粒子聚成目标形状并在形态之间切换，控制粒子数量和渲染分辨率。 | [粒子聚合](motion.md#particle-morph)，图片不能证明粒子数量、算法与连续形变。 |
| 03 遮罩揭开 / Mask Reveal | 以逐步变化的遮罩显露图片或区域，明确点击、进视口或滚动进度触发；完成后完整显示。 | [揭开完成态](motion.md#mask-reveal)，检查中间路径、圆角与减弱动态。 |
| 04 液态扭曲 / Liquid Distortion | 让指针附近的图片产生局部波纹与 UV 位移，离开后逐步平复；前景文字与控件保持独立。 | 用受控图片的 Canvas／WebGL 装饰层实现时检查跨域与设备能力；失败时展示静态图片。不要扭曲整页 DOM 或正文。 |
| 05 滚动叙事 / Scroll Storytelling | 在限定的固定展示区中，按滚动阶段切换产品视角、文字或场景，结束后回到正常文档流。 | 复用 [滚动叙事](motion.md#scroll-storytelling)，先设计内容顺序，再分配滚动区间。 |
| 06 卡片堆叠 / Stacking Cards | 让步骤卡逐层覆盖，保留后方卡片边缘、阅读顺序和退出区间。 | [卡片堆叠](motion.md#stacking-cards)，窄屏长内容不能被固定高度遮挡。 |
| 10 横向滚动 / Horizontal Scroll | 将限定展陈区的滚动进度映射为横向位移，展示时间线或展品。 | [横向展陈](motion.md#horizontal-scroll)，触摸与键盘可达，不全站拦截滚轮。 |
| 14 视差滚动 / Parallax | 让背景、中景、前景以不同幅度随滚动移动，保留空间层次。 | 复用 [视差](motion.md#parallax)，深度层的正文仍清晰，减弱动态时静止。 |

## 导航、浏览与指针

| 效果 | 实现提示词 | 核对 |
|---|---|---|
| 07 共享元素转场 / Shared Element Transition | 列表到详情时，用稳定对象标识把同一图片或卡片从源位置连续过渡到目标位置，返回时恢复。 | 按项目能力选择现有动画库或 View Transitions；核对尺寸、裁切和返回路径，不用整页淡入代替。浏览器不支持时仍正常导航。 |
| 08 无限画廊 / Infinite Gallery | 实现可向多个方向拖动浏览的图墙，使用循环坐标或有界窗口复用元素，释放后以有限惯性稳定停下。 | 区别于单列跑马灯和瀑布流；控制 DOM／纹理数量，提供键盘或普通列表替代入口。 |
| 09 物理掉落 / Physics Drop | 让少量标签受重力掉落、碰撞并可拖拽，边界随容器尺寸调整。 | 保持视觉层与点击、焦点、语义一致；只有真实需要碰撞时才引入物理求解。减弱动态时静态排列。 |
| 11 页面转场 / Page Transition | 用单一遮罩或整体淡入淡出衔接当前与下一页，导航立即响应，过渡可中断。 | 保留 URL、浏览历史、滚动恢复和焦点管理；只在页面准备好时揭开，不能动画完才开始请求。 |
| 12 光标跟随 / Custom Cursor | 为支持精细指针的设备增加情境视觉反馈，在可点击区域切换提示，离开后恢复。 | 复用 [情境光标](web-interactions.md#contextual-cursor)，不影响命中区域、系统文本选择与触摸操作。 |
| 13 悬停预览 / Hover Reveal | 当条目获得悬停或键盘焦点时，显示该条目的对应图片，离开后恢复。 | 复用 [图片预览](web-interactions.md#hover-image-preview)，触摸可点击展开，不让信息只能 hover 获取。 |
| 15 乱码解码 / Scramble Text | 让短标题从临时字符逐步解码为完整真实文字。 | 复用 [乱码解码](motion.md#scramble-text)，辅助技术只读取最终文本，避免长段落持续闪动。 |
| 16 磁吸 / Magnetic | 按指针到按钮中心的距离，限制范围地偏移视觉层，离开后回位。 | 复用 [磁吸](motion.md#magnetic)，点击区域和焦点保持稳定，不能让按钮逃离指针。 |

## 状态变化与时间节奏

| 效果 | 实现提示词 | 参考与核对 |
|---|---|---|
| 17 布局动画 / Layout Animation | 排序、筛选或重排时保留元素身份，使其从当前位置移动到新布局，新增或移除另处理透明度。 | [布局完成态](motion.md#layout-animation)，稳定 key；实际验证连续筛选、退出和中断。 |
| 18 错峰 / Stagger | 将同一组元素的起始时间依次错开，控制总等待时间；业务状态和必要文本立即可用。 | 复用 [错峰](motion.md#stagger)，区别于随机延迟或布局重排。 |
| 19 弹性 / Spring | 对拖拽／滑动释放后的归位传入释放速度，让对象有质量感地收敛；日常高频操作控制回弹幅度。 | 复用 [弹性](motion.md#spring)，不把大型弹窗的普通入场默认改成大幅弹跳。 |
| 20 缓动 / Easing | 按入场、离场、屏内移动和手势释放分配曲线与时长 token，保持现有动画对象、触发和位移。 | 继续使用 [011 两段完整提示词](recipes/easing.md)，不另造一套冲突的曲线规范。 |

液态扭曲、共享元素转场、无限画廊、物理掉落和页面转场使用文字实现说明，不配静态图；不要用其他效果的图片推断其连续行为。可用 `motion/motion-rules` 及这些中英文名称检索到本指南的分类入口。

## 组合提示词

```text
先盘点当前界面的动画对象、触发、状态、曲线和时长，再为本次需求选择一种主要动效。
保留路由、数据与交互语义，明确滚动绑定、一次性入场、指针跟随或状态切换的区别。
优先复用项目已有动画能力；指针拖动阶段保持 1:1 跟手，释放后再按角色缓动或弹簧收敛。
装饰与正文分层；优先使用 transform 和 opacity，控制滤镜、测量、粒子数量和离屏更新。
减弱动态时保留完整内容与操作，取消非必要位移、缩放、回弹和持续运动。
在真实项目核对初始、触发、进行、完成、恢复及连续中断；说明修改文件与实际验证范围。
```
