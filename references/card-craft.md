# 卡片质感与结构

围绕当前项目选一种主材质、至多一种重点光效，再处理结构。保留组件接口、真实内容、图标含义、按钮行为和既有设计 token。下面 23 项是可独立选择的技巧，不要求同时叠加。

## 材质

| 技巧 | 适用与实现提示词 | 参考与边界 |
|---|---|---|
| 01 毛玻璃 / Glassmorphism | 给卡片背景使用半透明着色、背景模糊、细亮边和轻阴影，让背后色块隐约透出；正文单独保持清晰。不支持背景滤镜时回退到足够不透明的表面。 | 与液态玻璃的边缘折射分开选择；图中白色实心前态不作为毛玻璃完成效果。 |
| 02 液态玻璃 / Liquid Glass | 采用按主题与背景适配的共享材质 token，在可用能力下增强边缘折射，正文和控件保持独立清晰。 | 沿用 [010 完整配方](recipes/liquid-glass.md)，不要用毛玻璃替换已确认的折射行为。 |
| 03 全息 / Holographic Card | 只给勋章或限定卡添加低强度多色反光、细纹和表面高光；若需要跟手，根据指针位置调整装饰层，离开后归位。 | 适合少量强调卡；文字说明不附遮挡画面。高光不能扫白正文。 |
| 04 拉丝金属 / Brushed Metal | 用同向细纹、金属明暗和克制边缘高光形成实体感，文字继续使用清晰的真实内容。 | [金属效果](glass-materials.md#brushed-metal)；压印不用于低对比的关键操作。 |

## 边框、光与交互

| 技巧 | 实现提示词 | 参考与核对 |
|---|---|---|
| 05 静态渐变描边 | 仅强调推荐卡片，边框保持细、静态、与圆角同心。 | [渐变描边](motion.md#gradient-border)。 |
| 06 环绕流光边框 | 让渐变亮带沿边缘缓慢环绕，只动画边框装饰层。 | [流光边框](motion.md#flowing-border)，实际检查路径与循环接缝。 |
| 07 跑马灯描边 / Border Beam | 只有一小段亮光沿边框运行，其余边缘保持安静。 | 复用 [边缘流光](motion.md#border-beam)，区别于整个表面扫光。 |
| 08 聚光灯 / Spotlight | 将指针映射到卡片内局部径向亮区，离开时平滑退去；键盘焦点提供相应强调。 | 复用 [聚光](motion.md#spotlight)，不要滤镜化文字。 |
| 09 光晕 / Glow | 给单个重点卡片增加柔和的外部光晕，保持内部内容稳定。 | [外部光晕](motion.md#card-glow)；别给所有卡片同时发光。 |
| 10 发光分割线 | 细线中间微亮、两端渐隐，保持分区和上下间距。 | [分割线细节](interface-details.md#glowing-divider)。 |
| 11 3D 倾斜 / Tilt | 卡片小幅跟随指针倾斜，光源位置同步；离开或失焦后归位。 | 复用 [3D 倾斜](motion.md#tilt)，触摸不依赖 hover。 |
| 12 翻转 / Flip Card | 正面显示摘要，点击或明确触发后翻到背面；保留返回入口及键盘操作。 | 复用 [翻转卡片](cards-tables.md#flip-card)，不自动把既有悬停改成点击。 |
| 13 展开 / Expandable Card | 通过明确入口将摘要卡原位扩展为详情，保留关闭、返回与焦点恢复；周围布局或遮罩按实际产品语义决定。 | 展开改变展示范围；翻转切换正反面。若形成模态详情，沿用可靠模态组件的焦点与 Esc 管理。 |

动效跟随真实交互：指针移动时保持跟手；释放或离开后再缓动归位。不要给静态卡片默认添加无限循环倾斜。完整节奏采用 [011 动画节奏配方](recipes/easing.md)。

## 结构与底层细节

| 技巧 | 实现提示词 | 核对 |
|---|---|---|
| 14 卡片结构 / Card Anatomy | 按图标、标题、说明、操作组织内容，同类元素左对齐并统一内边距；约 24px 仅为示例起点。 | 使用真实内容检查长标题、多语言与窄屏。 |
| 15 等高 / Equal Height | 同排卡片由网格拉伸等高，内部用纵向布局，让按钮通过剩余空间自然贴底。 | 不写死所有卡片高度，不截断正文来凑齐；窄屏重排后恢复自然高度。 |
| 16 图标库 / Icon Library | 复用项目同一套线性图标，统一视框、笔画和视觉大小；约 24px 为起点，按已有组件规范调整。 | 避免 emoji 与线性图标混搭；纯装饰图标隐藏于辅助技术，操作图标有可访问名称。 |
| 17 图标底座 / Icon Container | 用品牌同色系的浅色圆角底座托住图标，统一底座尺寸与居中方式。 | 只改外观，不替换已有图标含义。 |
| 18 同色渐变 / Tonal Gradient | 在同一品牌色相内由浅到深，先保证前景文字与按钮对比。 | 复用 [基础渐变](backgrounds.md#gradient)，不强制流动。 |
| 19 网格渐变 / Mesh Gradient | 将多个柔和色团融合为背景，明确静态还是流动。 | 复用 [网格渐变](backgrounds.md#mesh-gradient)，避免高对比色团盖住文字。 |
| 20 噪点 / Grain | 仅在背景装饰层上叠加静态细噪点，约 5% 为试调起点。 | 复用 [噪点颗粒](backgrounds.md#grain)，文字与图标不参与滤镜。 |
| 21 纹理图案 / Pattern | 添加低对比小点、细网格等重复纹理，以平铺装饰层呈现。 | 与随机颗粒区分，密度按显示尺寸调整，避免摩尔纹。 |
| 22 内高光 / Inner Highlight | 上缘和内侧使用细微亮边，配轻阴影形成厚度，统一光源方向。 | [完成后的卡片布局](interface-details.md#inner-highlight)同时展示线性图标、底座、同色渐变与浅纹理，可复用同一张图。 |
| 23 嵌套圆角 / Nested Corners | 按内外容器和间距关系设置递进圆角，保持视觉同心。 | 复用 [连续圆角配方](recipes/continuous-corners.md)，不要把内外圆角机械设成相同值。 |

## 组合提示词

```text
优化当前卡片的质感。先检查现有结构、主题、组件库与交互，保留真实内容、数据接口和操作。
统一图标、标题、说明、按钮的对齐与内边距；同排卡片等高，按钮自然贴底，窄屏允许自然增高。
复用同一套线性图标，使用统一的品牌浅色底座。
按已选方向使用一种主材质，只为最重要的卡片增加一种边框或光效。
装饰层与文字、图标、焦点层分开，保留清晰文字、圆角和克制阴影。
动画跟随实际触发；尊重减弱动态，检查键盘、触摸、长内容、深浅主题与连续操作。
先说明选用的材质和触发，再修改代码，最后报告实际核对的状态。
```

图片用于识别已呈现的材质与版式。没有干净完成帧的技巧使用上面的文字提示词，不借用其他效果的图冒充，也不靠放大或涂抹处理遮挡。
