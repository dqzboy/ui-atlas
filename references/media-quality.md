# 查看清晰参考

组件与文字特效使用原片截图，保留原像素裁切后的尺寸。随包图片直接读取本地文件；其他页面图片首次按需下载，经大小与 SHA-256 校验后缓存。

```bash
python3 scripts/fetch_media.py <条目ID>
python3 scripts/fetch_media.py <条目ID> --media images
```

默认只读取一张代表图，`images` 查看该条目必要的不同状态或页面。同一效果不重复堆叠相近帧；加载按钮保留待提交、提交中和成功，错误与正确方案的对照用于理解差异。

## 清晰度与边界

- **159 张原片 WebP**：来自 1440×2160、2880×2160 或 2160×2880 原片，按原像素裁切，质量 95（纯效果页面图为 98），不放大、不锐化、不涂抹、不跨帧修补。随包提供，无需依赖尚未发布的下载地址。
- **1 张已有原片参考图的纯效果裁切**：看板从已核对的参考图中裁出 1336×836 UI，保留像素尺寸并以质量 98 编码，不声称能恢复素材原本没有的细节。
- **12 张播放器近原尺寸 WebP**：从 1440×2560 视频在播放器接近原尺寸的呈现中裁出效果区域，质量 98，保留裁切后的像素尺寸，不放大、不锐化、不涂抹。它们不是直接从原视频文件解码的原像素抽帧。已按独立文件检查文字、图标与边缘；分割线和布局网格为局部效果图。
- 新效果图只保留 UI 本体；讲解标题、栏目名称、参数标注和提示词面板改为文档说明。素材有遮挡或过渡模糊时不强行配图。
- **46 张精选 PNG**：保留独立原图与必要页面。其中 Web 微交互与导航参考宽度为 720 像素，适合观察布局与意图；原素材不具备的细节不能靠放大补出。
- **10 张配方 JPG、5 个配方 GIF**：沿用原有文件。静态图核对细节，连续片段仅证明片段中实际可见的行为。
- Blur-up、Blur Reveal 的模糊是刻意展示的过程，另有清晰完成态。不能把这种状态与素材分辨率不足混为一谈。

图片编号区分状态或页面，不代表固定时间间隔。连续运动、缓动、速度、短暂反馈与真实请求需要在目标项目中验证。

## 离线使用与维护

```bash
python3 scripts/fetch_media.py --all
python3 scripts/build_skill.py --with-media
python3 scripts/validate_library.py --check-media --check-quality
```

`--all` 获取全部有效媒体；`--with-media` 构建完整离线包并将参考链接切换到包内路径。默认包保留组件截图和配方媒体，更多页面图使用外部缓存。

[媒体清单](media-manifest.json)与[图片清单](media-quality.json)记录路径、尺寸、大小和校验值。随包文件使用 `bundled: true`；远程文件必须先在公开固定 Git 提交中可访问，不能借用不含新文件的旧版本生成地址。主仓库不携带原视频、重复图集或大体积讲解 GIF；普通完整历史克隆仍包含过去的大文件。
