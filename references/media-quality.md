# 查看清晰参考

总览用于选型；判断小字、边框、圆角、阴影、材质和图表时，使用独立图片，避免把拼图中的小格放大。

```bash
python3 scripts/fetch_media.py <条目ID> --media images
python3 scripts/fetch_media.py <条目ID> --media gif
```

仓库版和完整媒体包已将原尺寸参考接入各条目：`images` 优先返回经过校验的独立 PNG，`gif` 优先返回可用的大尺寸版本。默认 `preview` 优先返回一张原尺寸代表图；精简版未包含独立图时再使用轻量总览。细节素材未安装时，脚本明确提示总览限制；不会编造下载地址，也不会用放大图冒充高清原稿。

同一效果默认只留一张内容完整的代表图，连续变化用 GIF 展示；折叠与展开、正常与报错等必要状态分别保留。不同页面与布局可保留多图，已有独立稿时不重复保留包含相同页面的组合图。当前细节库共 284 张精选 PNG 与 5 段大尺寸配方 GIF。

## 现有素材

| 内容 | 可用细节 | 实际边界 |
|---|---|---|
| 58 组静态图集 | 108 张精选原尺寸 PNG，保留既有裁切 | 从保留的原始图片导出，避免再压缩成 JPEG；源图片已有的压缩不变 |
| 45 条视频参考 | 47 张合成总览前的精选独立 PNG | 旧导出已缩到 300–720 像素宽；目前缺少对应的更高清原片 |
| 111 条原 GIF 参考 | 125 张 GIF 原尺寸精选独立 PNG | 避免拼图缩小和再次 JPEG 压缩；原 GIF 的像素、色彩、源压缩限制仍在 |
| 1 条移动首页参考 | 4 张不同页面的 720 像素宽独立 PNG | 从保留视频重新抽帧；页面透视与镜头运动仍保留 |
| 10 份质感配方 | 默认随包提供的高清 JPG | 仅凭静态图不能确认完整交互 |
| 其中 5 份配方动图 | 690–1080 像素宽、15 fps、256 色 GIF | 从 2160×2880 原视频按已确认的片段与裁切重新导出；仍受 GIF 色彩限制 |

PNG 导出不缩放、不锐化、不涂抹、不跨帧修补，也不补画源素材不存在的细节。多图编号用于区分选中的参考，不能推断时间间隔或全部短暂状态；需要连续过程时查看保留的 GIF，并在实际项目验证。

## 分发与维护

仓库目录包含完整参考媒体，素材目录不再被 Git 忽略；默认生成的精简技能包保持轻量。原有公开媒体的固定提交、校验值和下载地址保留。细节库由 [清晰度清单](media-quality.json) 记录路径、尺寸、大小、SHA-256、来源类型与限制，不借用旧提交为新媒体生成地址。

本地素材齐全时，运行 `python3 scripts/build_skill.py --with-media` 生成 `dist/ui-atlas-offline.zip`。解压后得到完整技能目录，包含原有有效媒体与独立细节，离线可用；默认的 `python3 scripts/build_skill.py` 仍生成精简包。用 `python3 scripts/validate_library.py --check-media --check-quality` 校验完整目录。维护时可运行 `python3 scripts/sync_reference_media.py --restore`，从已校验缓存补回原有媒体，并同步每条参考的独立图片、尺寸与动图链接。

原有 412 个媒体已从校验缓存恢复到项目的对应目录；分类文档使用本地图片，完整版本无需联网即可查看。精简包构建时会切换为有效的固定版本地址，并保留自带的配方图片。后续取得更高清原片时，应从原片重新导出，并更新清晰度清单；不能通过放大旧 GIF 声称恢复原始细节。
