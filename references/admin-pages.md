# 清爽蓝白后台：逐页实现提示词

本文件定义页面组合，具体颜色与壳层数值以 [基础设计规范](admin-design.md) 为准，控件以 [组件规范](admin-components.md) 为准，动画以 [动效规范](admin-motion.md) 为准。命中本风格时先读公共壳层，再读本次需要的页面章节；将对应提示词和总提示词一起执行，不要求用户再次复制。

## 使用边界与尺寸口径

数值单位均为 CSS px。参考页面3840×2160是在1920×1080 CSS视口以DPR2渲染，不是3840 CSS宽页面；不要把图上的像素直接变成两倍CSS尺寸。系统字体可能改变字宽，长业务文案可以折行与增高，但不能因此把整个后台字号、间距和控件一起放大。

有独立参考的页面应保留区块顺序和视觉关系。列表、详情、编辑、发布、任务与权限等扩展页采用本文件的组合约定，属于同风格扩展，不声称已有逐页原稿。按目标产品需要创建页面；以下章节不是要求一次生成所有业务功能。

### 登录统一滑动拼图验证

本风格新建／完善的登录页统一采用“填写账号密码→点击登录→滑动拼图弹窗→服务端验证通过→继续认证”的交互。先执行必填与格式校验，有字段错误时定位字段、不弹挑战；验证图加载完成后才启用滑块。不要默认改成手输图形字符验证码、点击文字／图片选点或独立的“滑到底即通过”按钮。既有MFA、SSO／Passkey及后端认证契约继续保留；若受既有接口限制不能接入滑动挑战，说明具体缺项，不能只画成功动画假装完成认证。

**弹窗与布局：**使用已有可靠Dialog或原生模态dialog，标题“请完成安全验证”、右上关闭按钮，标题区与正文一条轻分隔。面板宽min(352px,100vw−32px)、20px圆角、panel面与共享轻阴影；header左右16、标题15／650、关闭入口30px，body上14、左右16、下16。图像320:180等比缩放、11px圆角、原尺寸清晰呈现，不放大低清缩略图；底图、缺口、透明拼图块和刷新入口来自同一次挑战。右上图内刷新按钮30px、半透明深色面配白色刷新图标，保留可访问名称。图像下间距12px，轨道与图像同宽、高50px、圆角999、轻中性底；滑块48×48居中于轨道内，白面与轻阴影，默认右chevron；提示“向右滑动填充拼图”在轨道内垂直居中。轨道只保留一条原有边界，不能把截图中的外扩蓝环再叠上；键盘聚焦以同一边界变色体现。遮罩沿用页面Dialog主题并可轻模糊，背景不可交互／滚动；窄屏保持左右16px安全空间，短屏内容可滚、关闭按钮可达。

**拖动与状态：**thumb随指针／手指位移实时跟随，不加easing、拖尾或spring；拼图位移按同一进度映射到图像实际可用行程，不能直接把轨道CSS px当作原图坐标。resize／缩放后重算图像与轨道行程；转换到挑战接口要求的坐标系后提交。起拖后可靠接收释放与pointercancel，取消时回到可重试态，不误判成功。滑块原生range或沿用已有可访问挑战组件；range有明确label、min/max/step和aria-valuetext，左右键可微调并用明确确认动作提交，不因每个键盘input事件连续发验证。图像说明不把挑战答案写入aria标签；若服务提供键盘／非视觉替代验证，保留等价入口。

状态至少覆盖loading→ready→dragging→verifying→success／error／expired：loading禁拖并显示加载反馈；释放后verifying锁当前进度、spinner替换thumb图标、防重复请求；失败就地红色说明和重试，不清空账号密码、不无限抖动；过期／刷新取得新challenge并将旧请求作废、进度归零。成功改为勾选与“验证通过”，短暂显示后关闭并继续同一次登录，动画不阻挡已完成的认证或重复提交。关闭／Esc取消本次挑战、释放监听与请求并返回登录入口，保留字段值；关闭或刷新后旧响应不能重新打开弹窗、改成通过或跳转。成功后认证失败仍在登录表单显示真实错误，验证凭证是否可重用遵从服务端契约，不无条件复用。

**接口约束：**沿用真实挑战接口取得challengeId、图片资源／尺寸及到期信息，提交当前challenge的偏移／必要轨迹，服务端确认后取得一次性验证凭证并随该次登录请求提交；字段名按目标接口适配。不能以拖到底、固定阈值、前端比对图片答案、setTimeout或本地布尔值代替服务端确认；未接后端时只能标明为演示交互，不能宣称登录保护已实现。凭据和验证token不写日志、截图、示例数据或localStorage；现有滑动验证服务／组件优先复用，不为视觉一致引入新供应商。

验收空字段、点击登录、加载失败、鼠标／触屏拖动、释放／取消、键盘调整与确认、失败重试、刷新／到期、关闭／Esc与焦点返回、验证中连续点击、旧响应晚到、验证通过后登录失败及成功跳转。浅深主题、390宽、短屏与200%缩放核对图像／轨道同宽、拼图与thumb同步、无双层蓝框、按钮不跳尺寸；明确分别记录视觉演示与真实服务端联调结果。参考截图仅复用布局和实现效果，不复制品牌、账号或录屏中的业务数据。

## 运行概览

## 高频内容与高级选项的渐进展示

列表筛选、设置、导出等存在大量选项时，默认展示完成常见任务必需的字段，其余低频选项放入有名称的“高级筛选／高级设置”折叠区。高频与低频由本产品任务决定，不机械限制成两个控件；必填项、影响结果的关键范围与权限说明不能藏在默认收起处。

- 折叠开关可键盘操作，展开状态与受控区域关联；同一区域只保留一个可靠折叠实现，不为换样式重建字段。收起保留值、dirty、校验和查询条件；收起期间内部控件不进入Tab顺序。
- 有启用的高级条件时，在入口或查询摘要显示真实数量／可读摘要；默认值、空值和有效值按业务区分，不能有隐藏条件仍过滤结果却完全无提示。重置清理实际条件并同步摘要，不只清空可见字段。
- 提交时高级区存在错误，自动展开该区并把焦点送到错误摘要或首个错误字段；不要让用户猜错误在折叠区内。若已提交值来自高级区，保存确认／结果摘要仍能理解关键影响。
- 详情元信息、文件列表与并列卡片复用[信息排版合同](admin-components.md#clean-admin-information-layout)，不在页面层临时用空格、固定正文高度或假占位凑齐。

按默认／展开／收起后有条件／重置／隐藏字段错误检查，增加窄屏、长标签与查询失败；条件和保存语义不因折叠改变。状态简单的页面不额外增加“高级”入口。
